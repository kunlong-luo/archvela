# 06｜地理数据与公共展示：地图、交通、空间数据新闻与公共交互报告

> 领域目标：把具有**位置、时间、规模、来源**的数据准确地解释给用户，并保证移动端、无障碍及低性能设备仍可理解。此卷依赖 [00 通用架构规范](./00_通用_单人产品工厂与前端架构规范.md)。技术范围仅限前端、浏览器数据展示及渲染；数据源服务本身不在本卷设计范围。

## 1. 应用场景与选型矩阵

| 场景 | 用户任务 | 核心技术栈 | 明确输出 |
|---|---|---|---|
| **交通运输可视化** | 查看车辆/列车轨迹、站点、拥堵与异常 | Next.js + MapLibre GL JS + deck.gl + ECharts | 路线筛选、轨迹回放、站点详情 |
| **物流配送地图** | 多路线、配送区域、送达进度 | React + MapLibre + deck.gl（大数据时） | 分区地图、状态卡、轨迹时间轴 |
| **公共数据开放仪表盘** | 按地区、时间、指标查询和对比 | Next.js/Astro + ECharts + TanStack Table | 数据地图、趋势图、原始数据表 |
| **互动数据报告/数据新闻** | 跟随叙事理解重要事实和指标 | Astro + D3/SVG + GSAP（按需） | 分章节的图文、标注与可访问表格 |
| **地理故事地图** | 以地点解释故事、历史或项目建设成果 | Astro/Next + MapLibre + SVG | 地图章节、地标、时间线 |
| **环境与气象空间展示** | 查看测点分布、变化趋势、风险区域 | Next.js + MapLibre/deck.gl + ECharts | 空间热力、质量等级、时间选择器 |
| **灾害风险信息地图** | 浏览官方发布的风险范围和避险说明 | MapLibre/OpenLayers + ECharts | 来源、数据日期、风险分级、替代文字 |
| **区域人口/经济专题可视化** | 比较地区差异、钻取指标 | Next.js/Astro + deck.gl/ECharts + D3 | Choropleth、区间统计、表格替代 |
| **文旅线路与文化遗产地图** | 选择路线、查看遗迹/景点与文化资料 | Astro + MapLibre + 适量 R3F/GLB | 地图导览、媒体故事、3D 预览 |
| **大型地理空间分析前端** | 海量散点、轨迹、六边形聚合、空间查询 UI | React + deck.gl + loaders.gl + MapLibre | GPU 聚合图层、图例、过滤器 |

### 1.1 地图引擎的职责

- **MapLibre GL JS**：主地图、矢量底图、地图交互、样式与相机。
- **deck.gl**：在地图上可视化大规模、结构化的点、线、弧、网格、聚合和 GPU 图层；只有普通几十个点时不必引入。
- **OpenLayers**：复杂投影、多源 OGC 服务、矢量编辑、专业地图图层；与 MapLibre 按需求二选一作为主地图，不必默认叠加两个引擎。
- **CesiumJS**：需要真三维地球、地形高程、3D Tiles 或飞行轨迹立体展示时才引入；区别于二维数据看板。
- **ECharts / D3 / SVG**：独立时间趋势、比例与分布解释，不强迫一切都在地图上显示。

## 2. 典型单页结构

```text
[顶端标题 / 数据版本 / 最后更新 / 来源说明]
[地区选择] [指标] [时间范围] [图层选择] [重置]
┌──────────────────────┬──────────────────────┐
│ 主地图 MapLibre      │ 指标和对象详情        │
│ + 可选 deck.gl 图层  │ ECharts + 列表       │
│ 轨迹/测点/分区       │ 统计、置信提示       │
└──────────────────────┴──────────────────────┘
[可访问数据表] [说明与口径] [下载/分享当前视图]
```

移动端：地图和详情改为上下布局或底部抽屉；地图交互以图层开关、点击选点为主，避免小屏多层覆盖。

## 3. 前端数据契约：空间、时间与来源不可混淆

```ts
export type SourceQuality = 'official' | 'partner' | 'research' | 'demo';
export interface GeoObservation {
  featureId: string;
  geometry: GeoJSON.Geometry;
  crs: 'EPSG:4326';  // 需先标准化，其他投影使用明确的转换器
  observedAt: string; // ISO 8601，观测时间
  publishedAt?: string; // 来源发布时间
  value: number | null;
  unit: string;
  source: {
    title: string;
    url?: string;
    quality: SourceQuality;
    retrievedAt: string;
  };
  isSimulated: boolean;
}
```

**规则**：

1. 地图颜色的含义、数值单位、时间戳和来源必须同时可见。缺测不当零，空白区不代表无风险。
2. 区分**观测时间、发布/更新日期、页面拉取日期**。使用本地时区时明确标识。
3. 坐标转换在可测试模块中完成；不可将经纬度直接当平面米坐标。
4. 数据脱敏与位置模糊化依赖数据分类；敏感个人轨迹不默认渲染真实精确位置。
5. 聚合后图例与数值应声明聚合方法与单位；大数据抽样必须标记。
6. 不能只用红/绿区别严重程度，必须搭配文本、图案或辅助列表。

## 4. 推荐前端目录及依赖方向

```text
src/
  app/
    map/                    # 地图路由壳
    reports/                # 数据报告路由
  features/
    geography/
      domain/               # GeoObservation、地图领域类型、坐标转换
      map/                  # 地图面板与交互
      layers/               # 点、线、轨迹、聚合、热力图
      selection/            # 选中对象与筛选规则
    time-range/
      model/
      ui/
    reporting/
      charts/
      accessible-table/
      storytelling/
  adapters/
    maplibre/               # 地图引擎桥接及卸载
    deckgl/                 # 可选 GPU 图层
    openlayers/             # 仅在选择该引擎时出现
  shared/
    ui/                     # 标签、筛选、提示、布局
    data-contracts/         # 通用时空契约
  assets/
    posters/                # 不支持地图时的静态替代
```

依赖单向：`domain ← adapters/feature logic ← UI/route`；不允许核心数据口径直接引用具体地图 Mesh、Layer ID。地图选择与图表更新通过单一前端状态模型或事件桥实现。

## 5. 地图/图表/叙事的分包策略

| 分包层 | 触发条件 | 应单独加载内容 | 禁止事项 |
|---|---|---|---|
| P0 入口壳 | 打开页面 | 标题、元信息、可读摘要、筛选与地图占位 | 首屏就下载全部底图和 3D 引擎 |
| P1 地图视图 | 用户进入地图可视区 | MapLibre 主模块、基础地图样式 | 在文章无地图页面加载地图包 |
| P2 大数据图层 | 开启轨迹/热力/聚合 | deck.gl、图层 Worker、格式解析器 | 默认加载所有图层所有时间点 |
| P3 专业 GIS | 使用投影/编辑/OGC | OpenLayers 特定模块 | 同一个页面无依据同时开两个主地图 |
| P4 三维地理 | 明确点击三维切换 | CesiumJS、地形/瓦片、3D Tiles | 把整个 Cesium 代码塞入普通 2D 页面 |
| P5 图表 | 打开报表或详情卡 | ECharts 的必要图表/组件 | 在地图壳 import 全部 ECharts 图表类型 |
| P6 报告动效 | 进入滚动章节 | GSAP / D3 专项模块 | 首屏滚动前直接初始化所有时间轴 |

**资产分包**：地图瓦片受授权与网络条件约束；数据根据地区/日期/视口请求，矢量要素提前简化（允许误差须留痕），静态替代图和摘要在无 WebGL 情况下仍可阅读。

### 5.1 Next.js 地图加载示意

```tsx
'use client';
import dynamic from 'next/dynamic';
const MapView = dynamic(() => import('./MapView'), {
  ssr: false,
  loading: () => <div role="status">正在加载地图…</div>,
});
export function GeographicDashboard() {
  return <section><h2>区域情况</h2><MapView /></section>;
}
```

这只是客户端边界的示意，真实工程还必须在 `MapView` 中销毁地图对象、观察者、事件与 WebGL 资源。

## 6. 四种特色产品的 MVP

### 6.1 公交/物流轨迹平台

- **MVP**：单区域、固定路线、动态点位、时间拖拽、站点卡、移动端抽屉。
- **先使用清楚标识的模拟数据**，未接真实源时不展示“实时运行”的宣传语。
- **验收**：时间改变后点位正确，地图和列表一致；切换路线时无旧轨迹残留。

### 6.2 公共数据交互报告

- **MVP**：一个正式主题、三项可验证指标、两张图、一张可访问数据表、一段讲述和完整口径。
- **验收**：读屏/键盘能访问核心指标，图形不出现误导性截断或歪曲比例。

### 6.3 环境/降雨测点地图

- **MVP**：GeoJSON 区域、测点状态、时间选择、趋势详情、来源与数据时效提示。
- **验收**：离线与旧数据必须显示不同状态，数值单位统一。

### 6.4 文化遗产故事地图

- **MVP**：一个主题区域、8–12 个有来源的地点、图片/文字导览、路线跳转；按需增加一个 3D 模型。
- **验收**：无地图时仍可按地点清单完成导览，媒体资源有许可说明。

## 7. 性能、可访问性与质量门禁

| 指标 | 建议初始门槛（不是引擎保底） | 验证方法 |
|---|---|---|
| 首屏信息可读 | 不等地图模块下载，HTML 就能看到标题/摘要/来源 | 禁用 JS / 慢 4G 测试 |
| 地图拖动性能 | 目标设备流畅无长时间卡顿；大图层分级 | Performance 面板 + 真实设备 |
| 点位/轨迹数量 | 先明确 1k/10k/100k 测试档，记录帧率 | 生成可复现实测数据 |
| 数据正确性 | 区域边界、单位、时间与图表值一致 | 金样本快照与确定性测试 |
| 降级 | WebGL 不可用时仍可阅读表格/静态图 | 禁用 WebGL 的浏览器测试 |
| 可访问性 | 焦点顺序、图例文本、键盘与读屏替代 | axe + 手工检查 |
| 清理 | 卸载地图路由后没有事件/Worker/WebGL 泄漏 | 多次进出路由内存快照 |
