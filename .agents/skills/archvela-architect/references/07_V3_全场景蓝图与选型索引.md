# 07｜V3 全场景目录：62 种实际产品的前端架构、技术选型与分包模板

> **版本 V3 · 2026-10-27**。这是前端/浏览器渲染领域的**应用场景索引**，与 00 通用规范及 01–06 六大领域卷共同使用。清单是候选应用产品模板，不表示项目已开发或技术已安装。

## 使用方法

1. 先在下面找到产品真实所属场景，允许跨领域组合但只能选一个主业务用户任务。
2. 打开对应 01–06 领域卷，按最小用户任务定义模块及交付切片。
3. 根据 [00 通用规范](./00_通用_单人产品工厂与前端架构规范.md) 的源码包、功能模块、JS Chunk、资产分包四层来设计。
4. 使用 `templates/` 的 ADR、项目实施和性能预算模板，记录差异化视觉方案与测试证据。
5. 每个项目先做一个可使用的核心任务闭环；不强迫现有 Pagevela/Voxnelo 重写框架。

## 01｜网站与商业展示（13 种）

此类产品首先解决：**自然搜索、品牌信任、转化路径**。优先验收：**LCP、SEO、互动可用、真实产品信息**。详见 [01_网站与商业展示.md](./01_网站与商业展示.md)。

### V3-01 · 简单企业官网

- **推荐前端/渲染技术**：Astro + TS + Tailwind + Lucide
- **核心用户任务**：了解企业、核实能力、浏览案例、联系询盘
- **前端功能模块**：Hero、产品目录、案例详情、双语导航、SEO metadata
- **四层分包/加载重点**：静态优先；表单作为 Island；案例图片按页面加载。源码包只抽实际复用能力；每个功能先在自己项目内聚合；根据路由和重资产建 Chunk；静态预览优先于重媒体。
- **区别于模板站的特色**：真实案例与原创排版而非通用模板堆叠
- **最小可交付 MVP**：首页、产品页、3条案例、联系入口
- **验收方向**：至少提供正常/空/错误/低性能或权限限制状态，记录LCP、SEO、互动可用、真实产品信息的验证结果。
