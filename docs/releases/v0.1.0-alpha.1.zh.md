# Archvela v0.1.0-alpha.1 — 首次 Alpha 发布说明（草案）

> **状态：候选发布说明，尚未发布。** 仅表示准备发布的内容；不得视作已创建 Git Tag、GitHub Release、安装包或已获发布批准。必须完成发布门禁并获得仓库所有者明确批准后，才能考虑使用 `v0.1.0-alpha.1` 标签。

Archvela 面向独立开发者和 AI Coding Agent，提供**场景驱动、可审查的前端架构决策**，不是无需人工监督的完整软件生产平台。

## 本次候选版本包含

- **62 个架构场景 / 六大领域**：企业网站及营销、SaaS/业务应用、数字孪生、教育和专业可视化、网页游戏、地理数据产品。大部分场景详细资料仍为**中文架构参考**，不是 62 套完整程序。
- **3 个可生成、可构建的 Starter**：V3-02 高品质营销站，V3-14 SaaS 运营工作台，V3-26 住宅概念数字孪生。住宅演示不是 BIM、施工图或测绘成果。
- **英文优先的跨 Agent Skill 入口**，保留中文参考，技术栈推荐以用户需求、现有工程、兼容性和维护成本为依据，不强迫迁移 Vue/React 等框架。
- **离线 Python 工具**：场景检索、架构 ADR 草稿、四层分包和性能预算、结构化规划合同、安全的 Starter 生成器。
- **已验证的工程基础**：20 个目标的安装器兼容性 L1、Python 单测、安全/依赖审查、三个 Starter 浏览器和构建测试。
- **评测基础设施**：盲评清单、证据校验、负面结果保留；**尚无任何实际模型效果评测成绩**。

## 安装示例（使用当前 GitHub 默认分支，非固定发行版）

```bash
npx --yes skills@1.7.4 add kunlong-luo/archvela --skill archvela-architect \
  --agent codex --agent claude-code --agent opencode --copy --yes
```

以上命令现在即可针对公开仓库安装，但**不会锁定未来发行版本**。正式发布后应先核验该 Release 的实际 Commit SHA，再根据仓库固定提交安装指引进行可复现安装。

不运行 AI 模型也能检索场景、预览架构文档：

```bash
python3 .agents/skills/archvela-architect/scripts/scenes.py --query "company website"
python3 .agents/skills/archvela-architect/scripts/new_project_docs.py \
  --scene V3-26 --project sample-home --output ./scratch/sample-home --plan-json
```

## 必须如实说明的限制

- **20 个安装目标 ≠ 20 个真实模型成功调用**。目前只验证 L0/L1；Codex、Claude Code、OpenCode 原生 L2/L3 效果未完成。
- 62 个场景不等于 62 套可运行模板；目前代码生成器只有 3 套 Starter。
- V3 场景原文主要是中文；英文速查与 Skill 入口不是完整译本。
- 涉及住宅、医疗、专业制图和隐私的数据，不能用示例代替真实认证、专业审查与设备测试。
- 发布前必须完成**版权/第三方许可来源核对、管理员分支保护、真实客户端冒烟验证及明确的所有者批准**。
